# 字格：字形图片导出器

这是一个完全在浏览器本地运行的字符图片导出网页。它会自动读取项目根目录的 `all.txt`，将每个唯一字符按同一套样式绘制成 128 × 128 的黑字白底 PNG，并将全部图片打包成 TAR 下载。

## 启动

在此目录运行：

```bash
npm run dev
```

然后访问 <http://127.0.0.1:8000>。

也可以使用：

```bash
python3 -m http.server 8000 --bind 127.0.0.1
```

请通过上述本地服务器打开页面。现代浏览器通常会阻止以 `file://` 方式直接打开的页面载入 JavaScript 模块和旁边的 `all.txt`。

## 使用方式

1. 页面会自动读取 `all.txt`；也可在“源文件”处更换任意 UTF-8 文本文件。
2. 上传 TTF 或 OTF 字体。字体只会进入当前浏览器标签页的内存，不会上传到任何服务器。
3. 调整字号、字重、加粗描边、斜体、横纵比例与位置。
4. 点击“导出全部图片”，得到一个包含全部 128 × 128 PNG 的 TAR 文件。

换行和制表符作为排版分隔符忽略，普通空格会作为字符导出。重复字符只生成一次。为兼容 Windows 大小写不敏感的文件系统，英文字母会命名为 `大写字母A.png`、`小写字母a.png`。常见中英文标点会改用汉字释义命名，例如 `感叹号.png`、`斜杠.png`、`左圆括号.png`；数字、汉字等使用字符自身命名。
